# Changelog

## [2.0.0] — Unified Edition

- Unified private publishing workspace, content studio, approvals, delivery, recovery and optional research/artwork.
- Public static dashboard with visual GitHub and ChatGPT setup and copyable prompts.
- Clean repository template and root-ready GitHub Pages hosting; owner template activation is required.
- Offline regression, dependency audit, source scan, API contract and browser acceptance gates. Live provider access and individual account configuration must be verified separately.

## [1.0.0] — Community release candidate

- Official LinkedIn member text and image posting via authorised OAuth token.
- Multi-post UTC queue supporting multiple original posts per day.
- Persistent content fingerprint claims prevent exact/normalised duplicate submissions.
- Original adaptive 1200×1200 PNG educational visuals using Pillow.
- GitHub Actions CI regression suite, dependency audit (pip-audit) and Python security scan (Bandit).
- Private deployment with live publishing disabled by default and independent user credentials.
- Beginner visual setup guides and provider-neutral research prompts.

Known limitations: LinkedIn v2 compatibility may change; repeated content expressed in different words may not be detected; unsuccessful or ambiguous API requests require manual review; scheduling and AI research require an external assistant; potential image-display variations are not independently verified. No unrestricted publishing guarantee or guaranteed zero cost.
