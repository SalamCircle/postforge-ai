Privacy & Security

Updated 25 November 2026

Workspace data

Drafts, brand settings, requests, queue entries and receipts may be stored in your GitHub repository and its history. Publishing sends selected content to LinkedIn. GitHub and LinkedIn process data under their own policies.

Credentials

The mobile app uses scoped GitHub tokens. By default the connection token is held in the tab; optional saved authorisations are encrypted using a device passphrase. LinkedIn and optional provider keys belong in private repository secrets, not in the browser or content. Encryption does not eliminate device or website compromise risks.

Control and retention

Forget saved connections and editing authorisations on the device, revoke tokens with the issuing provider and manage repository data and LinkedIn posts separately. Deleting a draft does not necessarily erase Git history, provider records or published posts.

For provider privacy information see GitHub and LinkedIn. Deployment operators must provide their own identity, contact and applicable privacy information where required.
