## Caption

🚀 **PostForge AI is now open source!**

I've been working on a project that combines AI-assisted content creation, Python, GitHub Actions and secure LinkedIn publishing.

Today I'm sharing **PostForge AI** — a community edition that developers and students can inspect, learn from and adapt.

It supports:
- AI-assisted content research through a connected LLM
- Original educational graphics
- Automated LinkedIn publishing through official APIs
- Multiple original posts per day
- Content-fingerprint duplicate protection
- Independent user credentials and private deployments
- Beginner-friendly setup guides

A key lesson from building this has been that publishing automation isn't just about making an API request. It also means validating content, handling uncertain results, avoiding duplicates and keeping credentials separate.

I've made the source available under the MIT licence, with automated tests and security checks.

Explore the repository: https://github.com/SalamCircle/postforge-ai

If you're interested in AI, cybersecurity or automation, I'd welcome your feedback. Feel free to explore the code, open an issue or star the project if it's useful.
