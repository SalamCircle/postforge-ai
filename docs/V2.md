# PostForge AI V2 — development preview

This branch adds offline tooling only. No new API calls, credentials, scheduled jobs or production changes.

Run from the repository root with Python 3.9+ and timezone data:

```sh
python -m unittest discover -s tests -v
python scripts/v2_manager.py history
python scripts/v2_manager.py queue
python scripts/v2_manager.py plan comment "Selected post URL" --text "Reviewed comment"
python scripts/v2_manager.py plan reaction "Selected post URL" --text LIKE
python scripts/v2_manager.py plan delete "Own post URN"
python scripts/v2_manager.py schedule-preview 2026-12-01T14:30
```

Use any LLM to prepare drafts based on supplied content. Plans are not executable requests and never imply approval. Schedule previews convert time zones but do not schedule a job. Existing daily and on-demand publishing stays on main.

Next gates: verify official API product access for edits/deletes and engagement, add mocked endpoint tests, explicit approval and ownership checks, then separately test an authorised live action. Profile editing is restricted and remains draft-only. Never scrape feeds or bypass API restrictions. No paid dependencies or new services are required for this preview.

Do not merge until the full regression suite passes. Check Actions quota and disable paid overages before enabling additional workflows.
