# PostForge AI V2 — development roadmap

V1 remains supported independently. V2 is not yet available for installation. Planned upgrade and fresh-install routes will be linked here after testing and clean-source release.

V2 currently has offline queue/history tools, draft planning and timezone previews in private development. Live engagement requires official API permissions; profile editing is restricted. No mandatory paid subscription is planned.

## Independent accounts

Use separate private deployments for separate authorised accounts, each with its own token, queue and receipts. For an upgrade of the same account, stop V1 before enabling V2 and migrate receipts safely.
